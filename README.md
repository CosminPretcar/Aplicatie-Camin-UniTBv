# Aplicatie-Camin-UniTBv

**Aplicatie-Camin-UniTBv** is a student-focused platform for managing university dormitory workflows at **UniTBv**—from requests and announcements to room-related information and communication, in one place.

---

## Features
- Centralized access to dorm announcements and important updates
- Submit and track requests (e.g., maintenance / admin inquiries)
- Resident profile and dorm/room information overview
- Admin/staff tools for handling submissions and communication
- Clear status updates and history for actions/requests
